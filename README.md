# Notifications and automation for ForgeFIRM

`org.openglow.automation`, an official ForgeFIRM extension package: a native
service that turns the machine's events into notifications, requests to your
own devices, and MQTT messages, and can hold a job until the exhaust is on;
and its page in the control panel.

It is also an example of a package's repository: a native service built for
the machine, its unit tests, a test under the real extension host, and
forgeext's shared workflow, which tests and packs it on every push and signs
and publishes each new version as a release. The catalog does not list it.
